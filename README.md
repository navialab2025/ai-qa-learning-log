# AI品質保証（QA）& セキュリティ検証ポートフォリオ

ようこそ！本リポジトリは、AI（LLM）を組み込んだ業務アプリケーションにおける**「ハルシネーション（嘘）」「出力フォーマット崩壊」「プロンプトインジェクション」**などのリスクを未然に防ぎ、現場で安全に使えるAIシステムを担保するための検証ログ・ポートフォリオです。

大手企業が「AIの導入・コスト削減」ばかりに目を向ける中、私は**「導入後の現場で暴走しない、本当に実務で使えるAI品質」**を追求しています。

---

## 私の強み（クライアント企業様へ提供できる価値）

1. **実務現場に即した「バグを見つける目」**
   * 製造業や自営業など、リアルな現場での実務・業務改善経験をベースに、「現場のユーザーがどう操作し、どうAIが誤作動するか」のリアリティを持ったテスト設計を行います。
2. **AI特有の挙動（ハルシネーション・JSON崩壊）への対策能力**
   * ChatGPTやGeminiなどのAPI連携時に発生しやすい「期待したフォーマット（JSONなど）で返ってこない」「指示を無視する」といった現象の再現・原因特定・プロンプト改善案の提示が可能です。
3. **Webセキュリティの基礎とAI堅牢化（現在強化中）**
   * PortSwigger等を用いたWebセキュリティ（SQLインジェクション等）の基礎知識を有し、AIに対する悪意ある入力（プロンプトインジェクション）からシステムを守る防御策を検証しています。
